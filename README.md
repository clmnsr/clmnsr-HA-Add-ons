\# Clemens HA Add-ons



Welcome to my custom Home Assistant Add-on repository. 



Currently, this repository features a specialized version of the \*\*OctoEverywhere Companion for Klipper\*\*. It is designed to work out-of-the-box with standard Klipper/Moonraker setups, as well as heavily modified firmwares (like OpenCreator or ZMOD).



\## 📦 Available Add-ons



\### OctoEverywhere for Klipper (`oe\_klipper`)

Run the OctoEverywhere Companion directly inside Home Assistant. 

\* \*\*Smart UI Configuration:\*\* Set or change your printer's IP address directly via the Home Assistant Add-on UI.

\* \*\*Auto-Reset Logic:\*\* Automatically handles pairing resets and token cleanups when IP addresses change or when manually requested.



\## 🚀 Installation



You can add this repository to your Home Assistant instance with a single click:



\[!\[Open your Home Assistant instance and show the add add-on repository dialog...](https://my.home-assistant.io/badges/supervisor\_add\_addon\_repository.svg)](https://my.home-assistant.io/redirect/supervisor\_add\_addon\_repository/?repository\_url=https://github.com/DEIN-GITHUB-NAME/DEIN-REPO-NAME)



\*(Alternatively, go to Settings -> Add-ons -> Add-on Store -> Top right menu -> Repositories -> Paste the URL of this repository).\*
